Verificar ISRC e código UPC/EAN

Cole um código para saber se é válido e o que ele contém. O ISRC identifica uma gravação; o UPC ou EAN identifica o lançamento inteiro. Um erro de digitação pode travar o lançamento ou mandar os royalties para o lugar errado.

Como é um ISRC

  • 2 letras: o país de quem registra (BR, PT, US…)
  • 3 caracteres: o código do registrante, dado à gravadora ou distribuidora
  • 2 dígitos: o ano em que o código foi atribuído (não o ano de lançamento)
  • 5 dígitos: o número da gravação
  • 12 caracteres no total; os hífens servem só para leitura, ex. BR-A1B-25-00001

Onde conseguir os códigos

Quase todas as distribuidoras (DistroKid, RouteNote, TuneCore, CD Baby, Amuse…) atribuem ISRC e UPC de graça no envio. Se a gravação já saiu, reutilize o ISRC dela: a mesma gravação mantém o mesmo código em todo lançamento.

ISRC ou UPC?

Uma gravação = um ISRC, onde quer que apareça. Um lançamento = um UPC ou EAN. Um EP de 5 faixas tem um UPC e cinco ISRCs.

FAQ

Como verifico se um ISRC é válido?

Cole acima: a ferramenta confere o tamanho, as letras do país, o código do registrante, o ano e o número. O ISRC não tem dígito verificador, então um formato válido não prova que o código foi registrado: use o link do Spotify ou do MusicBrainz para achar a gravação.

Como confiro um código de barras UPC ou EAN?

Cole os 12 (UPC) ou 13 (EAN) dígitos. O último é o dígito verificador: se houver erro de digitação, a ferramenta diz qual deveria ser.

Posso reutilizar um ISRC num remix ou numa nova versão?

Não. Remix, remaster, versão ao vivo ou radio edit são gravações diferentes e precisam de ISRC próprio. A mesma gravação lançada como single e depois no álbum mantém o ISRC.

Algo é enviado para um servidor?

Não. A checagem acontece no seu navegador. Os links de busca só abrem o Spotify ou o MusicBrainz se você tocar neles.
