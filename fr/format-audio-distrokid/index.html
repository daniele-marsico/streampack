Format audio pour DistroKid et Spotify

Le fichier accepté par tous les distributeurs est un WAV ou FLAC stéréo en 44,1 kHz, 16 bits. Si votre morceau est un M4A, un MP4, un OGG, un enregistrement de téléphone ou un fichier en 48 kHz, StreamPack le convertit exactement ainsi.

Quand StreamPack vous sert, et quand non

Si votre STAN a déjà exporté un master WAV ou FLAC que votre distributeur accepte, envoyez-le tel quel : Spotify demande le master d'origine, sans réduction de qualité. StreamPack sert dans les autres cas : le fichier est dans un format refusé, il est en 48 kHz ou en mono, ou vous avez un doute. Vous obtenez un WAV ou FLAC stéréo en 44,1 kHz et 16 bits accepté partout.

Noms de fichiers

DistroKid refuse les noms de fichiers contenant \ / : * ? " ' < > |. StreamPack nomme les fichiers avec votre nom d'artiste et le titre, sans ces caractères.

FAQ

WAV ou FLAC pour DistroKid ?

Les deux sont sans perte, le son est identique. Les FLAC sont plus légers : pratique pour les morceaux longs ou les albums.

Un MP3 suffit-il ?

Certains distributeurs acceptent le MP3, mais le WAV ou le FLAC est recommandé : les plateformes réencodent le fichier, et partir d'un MP3 fait perdre plus de qualité.

Faut-il envoyer du 24 bits ?

Si votre master est en 24 bits et que votre distributeur l'accepte, oui. Amuse n'accepte que le 16 bits ; dans le doute, le 16 bits 44,1 kHz passe partout.
