Vérifier un ISRC et un code UPC/EAN

Colle un code pour savoir s'il est valide et ce qu'il contient. L'ISRC identifie un enregistrement ; l'UPC ou l'EAN identifie toute la sortie. Une faute de frappe peut bloquer une sortie ou envoyer les droits au mauvais endroit.

Comment est fait un ISRC

  • 2 lettres : le pays du déclarant (FR, BE, CA…)
  • 3 caractères : le code du déclarant, attribué au label ou au distributeur
  • 2 chiffres : l'année d'attribution du code (pas l'année de sortie)
  • 5 chiffres : le numéro de l'enregistrement
  • 12 caractères au total ; les tirets servent seulement à la lecture, ex. FR-A1B-25-00001

Où obtenir tes codes

Presque tous les distributeurs (DistroKid, RouteNote, TuneCore, CD Baby, Amuse…) attribuent gratuitement les ISRC et l'UPC à l'envoi. Si un enregistrement est déjà sorti, réutilise son ISRC : le même enregistrement garde le même code sur chaque sortie.

ISRC ou UPC ?

Un enregistrement = un ISRC, où qu'il apparaisse. Une sortie = un UPC ou EAN. Un EP de 5 titres a un UPC et cinq ISRC.

FAQ

Comment vérifier si un ISRC est valide ?

Colle-le ci-dessus : l'outil contrôle la longueur, les lettres du pays, le code du déclarant, l'année et le numéro. Un ISRC n'a pas de chiffre de contrôle, un format valide ne prouve donc pas que le code est enregistré : utilise le lien Spotify ou MusicBrainz pour retrouver l'enregistrement.

Comment vérifier un code-barres UPC ou EAN ?

Colle les 12 (UPC) ou 13 (EAN) chiffres. Le dernier est un chiffre de contrôle : en cas de faute de frappe, l'outil t'indique lequel il devrait être.

Puis-je réutiliser un ISRC pour un remix ou une nouvelle version ?

Non. Un remix, un remaster, une version live ou un radio edit est un autre enregistrement et demande son propre ISRC. Le même enregistrement sorti en single puis sur l'album garde son ISRC.

Quelque chose est-il envoyé à un serveur ?

Non. Le contrôle se fait dans ton navigateur. Les liens de recherche n'ouvrent Spotify ou MusicBrainz que si tu les touches.
