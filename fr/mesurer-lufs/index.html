Ce que veulent dire les chiffres

  • LUFS intégrés : la loudness moyenne de tout le morceau, le chiffre que les plateformes utilisent pour régler le volume
  • True peak (dBTP) : le niveau le plus haut de l'onde reconstruite entre les échantillons. Au-dessus de -1 dBTP, les versions MP3 et AAC peuvent saturer
  • Plage de loudness (LU) : à quel point le niveau varie entre les passages doux et forts. Une valeur basse indique un morceau très compressé

En streaming, plus fort n'est pas mieux

Spotify, YouTube et les autres plateformes baissent les masters trop forts jusqu'à leur niveau. Un morceau à -8 LUFS joue environ 6 dB plus bas sur Spotify et garde le son écrasé du limiteur. Vise environ -14 LUFS avec un true peak à -1 dBTP ou moins, sauf si tu veux un master fort exprès.

FAQ

Combien de LUFS pour un morceau sur Spotify ?

Spotify joue la musique à -14 LUFS. Un master plus fort est baissé ; un master plus doux n'est monté que dans la limite de ses crêtes. -14 LUFS avec un true peak à -1 dBTP est un objectif sûr.

Cette mesure est-elle précise ?

Elle utilise la pondération K et le gating de l'ITU-R BS.1770 pour la loudness intégrée, l'EBU Tech 3342 pour la plage de loudness et un suréchantillonnage 4× pour le true peak. Les résultats correspondent aux mesureurs professionnels à quelques dixièmes de dB près.

Pourquoi le true peak est-il plus haut que la crête des échantillons ?

Entre deux échantillons, l'onde reconstruite peut monter plus haut que les deux. Ces crêtes inter-échantillons apparaissent quand le fichier devient MP3 ou AAC : c'est pour ça que les plateformes demandent -1 dBTP.
