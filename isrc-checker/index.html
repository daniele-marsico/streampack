How an ISRC is built

  • 2 letters: country of the registrant (US, GB, IT…)
  • 3 characters: registrant code, given to the label or distributor
  • 2 digits: the year the code was assigned (not the release year)
  • 5 digits: the number of the recording
  • 12 characters in total; hyphens are only for reading, e.g. US-S1Z-25-00001

Where to get your codes

Most distributors (DistroKid, RouteNote, TuneCore, CD Baby, Amuse…) assign ISRCs and the UPC for free when you upload. If a recording is already out, reuse its ISRC: the same recording keeps the same code on every release.

ISRC or UPC?

One recording = one ISRC, wherever it appears. One release = one UPC or EAN. A 5-track EP has one UPC and five ISRCs.

FAQ

How do I check if an ISRC is valid?

Paste it above: the checker verifies the length, the country letters, the registrant code, the year and the number. ISRCs have no check digit, so a valid format doesn't prove the code was registered: use the Spotify or MusicBrainz link to find the recording.

How do I check a UPC or EAN barcode?

Paste the 12 (UPC) or 13 (EAN) digits. The last one is a check digit: if there's a typo, the checker tells you which digit it should be.

Can I reuse an ISRC for a remix or a new version?

No. A remix, a remaster, a live version or a radio edit is a different recording and needs its own ISRC. The same recording released as a single and later on an album keeps its ISRC.

Is anything sent to a server?

No. The check runs in your browser. The search links open Spotify or MusicBrainz only if you tap them.
