So ist ein ISRC aufgebaut

  • 2 Buchstaben: Land des Registranten (DE, AT, US…)
  • 3 Zeichen: Registrant-Code, vergeben an Label oder Vertrieb
  • 2 Ziffern: das Jahr, in dem der Code vergeben wurde (nicht das Release-Jahr)
  • 5 Ziffern: die Nummer der Aufnahme
  • Insgesamt 12 Zeichen; Bindestriche dienen nur der Lesbarkeit, z. B. DE-A1B-25-00001

Woher du die Codes bekommst

Fast alle Vertriebe (DistroKid, RouteNote, TuneCore, CD Baby, Amuse…) vergeben ISRC und UPC beim Upload kostenlos. Ist eine Aufnahme schon erschienen, nutz ihren ISRC weiter: Dieselbe Aufnahme behält auf jedem Release denselben Code.

ISRC oder UPC?

Eine Aufnahme = ein ISRC, egal wo sie erscheint. Ein Release = ein UPC oder EAN. Eine EP mit 5 Songs hat einen UPC und fünf ISRCs.

FAQ

Wie prüfe ich, ob ein ISRC gültig ist?

Füg ihn oben ein: Das Tool prüft Länge, Länderbuchstaben, Registrant-Code, Jahr und Nummer. ISRCs haben keine Prüfziffer, ein gültiges Format beweist also nicht, dass der Code registriert ist: Nutz den Link zu Spotify oder MusicBrainz, um die Aufnahme zu finden.

Wie prüfe ich einen UPC- oder EAN-Barcode?

Füg die 12 (UPC) oder 13 (EAN) Ziffern ein. Die letzte ist eine Prüfziffer: Bei einem Tippfehler sagt dir das Tool, welche Ziffer es sein müsste.

Darf ich einen ISRC für einen Remix oder eine neue Version wiederverwenden?

Nein. Remix, Remaster, Live-Version oder Radio Edit sind andere Aufnahmen und brauchen einen eigenen ISRC. Dieselbe Aufnahme als Single und später auf dem Album behält ihren ISRC.

Wird etwas an einen Server geschickt?

Nein. Die Prüfung läuft im Browser. Die Suchlinks öffnen Spotify oder MusicBrainz nur, wenn du sie antippst.
