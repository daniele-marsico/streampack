Qué significan los números

  • LUFS integrados: la sonoridad media de toda la canción, el número que usan las plataformas para ajustar el volumen
  • True peak (dBTP): el nivel más alto de la onda reconstruida entre muestras. Por encima de -1 dBTP, las versiones MP3 y AAC pueden distorsionar
  • Rango de loudness (LU): cuánto cambia el nivel entre partes suaves y fuertes. Valores bajos indican una canción muy comprimida

En streaming, más fuerte no es mejor

Spotify, YouTube y las demás plataformas bajan los másteres demasiado fuertes hasta su nivel. Una canción a -8 LUFS suena unos 6 dB más baja en Spotify y conserva el sonido aplastado del limitador. Apunta a unos -14 LUFS con true peak de -1 dBTP o menos, salvo que quieras un máster fuerte a propósito.

FAQ

¿Cuántos LUFS debe tener una canción para Spotify?

Spotify reproduce la música a -14 LUFS. Un máster más fuerte se baja; uno más suave se sube solo hasta donde lo permiten sus picos. -14 LUFS con true peak de -1 dBTP es un objetivo seguro.

¿Es precisa esta medición?

Usa la ponderación K y el gating de ITU-R BS.1770 para la sonoridad integrada, EBU Tech 3342 para el rango de loudness y sobremuestreo 4× para el true peak. Los resultados coinciden con los medidores profesionales en pocas décimas de dB.

¿Por qué el true peak es más alto que el pico de las muestras?

Entre dos muestras la onda reconstruida puede subir más que ambas. Esos picos entre muestras aparecen al pasar el archivo a MP3 o AAC: por eso las plataformas piden -1 dBTP.
