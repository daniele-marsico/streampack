What makes a good YouTube description
The first one or two lines matter most: they appear in search and above the "more" button, so say clearly what the viewer will get and use the words people search for. Below that, a short summary and a few bullet points help viewers and YouTube understand the video. Add your links, chapters (timestamps starting at 0:00) if the video is long, one call to action and a few hashtags. Keep it honest: the description should match the title, thumbnail and video.


FAQ
How long should a YouTube description be?
YouTube allows up to 5,000 characters, but only the first lines show in search results and above the "more" button. Put what the viewer gets and your main keyword in the first one or two sentences; 200-400 words in total is plenty for most videos.
How do hashtags in the description work?
If your title has no hashtags, YouTube can show the first 3 hashtags from your description next to the title. According to YouTube's own rules, a video with more than 60 hashtags has all of them ignored, so this tool adds just 3 relevant ones.
